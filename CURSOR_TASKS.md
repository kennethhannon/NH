# Cursor task brief: PracticalKit monetization sprint
Repository: kennethhannon/NH

Objective: finish one reliable, sellable workflow before adding unrelated features.

1. Run `npm test` and the GitHub Quality Gate. Do not call beta apps production-ready without end-to-end browser tests.
2. Fix bugs with a regression test. Do not remove disclaimers.
3. Focus first on FinishLine: add editable issues, before/after image evidence, report numbering/date, and a polished print-to-PDF layout. Use safe DOM APIs, not unsanitized innerHTML.
4. Avoid cloud sync or payments without explicitly approved credentials and a security/privacy design.
5. Open a PR for every distinct improvement; include screenshots of mobile + desktop, test results, and limitations. Do not fabricate reviews, users, sales, or quotes.
6. Keep zero-paid-dependency static hosting until customers validate value.
